# Essence Elite

Estou criando uma empresa de suplementos, e preciso de um site. Trabalhamos com um publico alto padrão, com dinheiro e exigente. 
Quero um site clean, mas com alguns efeitos. 
Os botões precisam ser um pouco arredondado e precisa manter as definições da nossa marca, que estão nas imagens enviadas.

Faça um sitwe completo. 
Quero com integração futura, quero que funcione o botão de ir pro carrinho funcione, quando adicionar um item ao carrinho, ele deve ir lá, já com valor. 

Quero ele completo já para vendar um produto ainda hoje.
